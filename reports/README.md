# Analysis reports

These files are generated by `python3 scripts/analyze_ast.py`.
They are review artifacts, not a second trading bot.

- `ast_report.json` — imports, classes, BUY/SELL/HOLD strings, `create_order` sites
- `dependency_graph.json` — import graph
- `file_inventory.json` / `FILE_INVENTORY.md` — path, role, in-use vs leftover wiki HTML
- `completion_spec.json` — verifiable checks (live POST is NOT_TESTED)

Regenerate:

```bash
cd <repo>
PYTHONPATH=src python3 scripts/analyze_ast.py
PYTHONPATH=src python3 scripts/dump_all_source.py
PYTHONPATH=src python3 scripts/completion_percent.py
```

`reports/trading_bot_all_source.txt` is gitignored. It is **not** executable.
The runnable program remains `bash ./start.sh` → `python -m bitbank_bot`.
